# Supplementary information for the KíLín article

The `clean_repository.ipynb` export includes this directory and applies
explicit safety rules to its children:

| Directory | Source ZIP policy |
|---|---|
| `benchmarks/` | Include Git-tracked source notebooks, gold data, and helpers; export `sandbox/` and `results/` empty. |
| `code_repo/` | Export an empty directory; keep the populated corpus in Git. |
| `literature_repo/` | Export an empty directory; keep the populated corpus in Git. |
| `code_analysis/` | Include Git-tracked analysis files and manuscripts. |
| `reference_analysis/` | Include only `.gitkeep` until analysis is added. |

The two populated source corpora remain eligible for Git tracking. Their
contents are omitted only from the ZIP to keep it small; no `.gitignore`
exclusion or `.gitkeep` is needed for either corpus. The exporter creates
both directory entries explicitly and cleanup never enters them.

## Code-analysis scripts

Run from the repository root, after installing the selected backend and
caching its models:

```bash
uv run --no-sync python _si_article_/code_analysis/code_example.py
uv run --no-sync python _si_article_/code_analysis/paper_numbers.py
```

Both scripts support `--help` without loading a model. They index a
committed revision (`--ref HEAD` by default), so a Git checkout is
required for a measurement run; an extracted source ZIP alone has no
revision history. Results are written to `code_analysis/results/`.
The question file is `code_analysis/code_questions.json`, and the shared
workspace remains at the repository-root `sandbox/paper_numbers/`.
These paths are resolved from the scripts, not the working directory.

Evaluation source exports exclude `_si_article_/` (questions, previous
results and corpora), `assets/`, `example_repos/` and the legacy
`benchmarks/` and `paper/` locations by default. This prevents evaluation
data from becoming retrieved evidence. `paper_numbers.py
--include-examples` deliberately disables these exclusions; use it only
for exploratory runs, not uncontaminated evaluation. This restriction
does not narrow ordinary KíLín cross-file retrieval. Existing recorded
results are historical data and are not regenerated by this change.

## Legacy benchmarks

Benchmark notebooks were relocated from the previous root `benchmarks/`
directory. Their storage paths and local helper imports were updated, but
some still refer to older QAChat package APIs. Their migration to current
KíLín interfaces requires separate verification before running them.
