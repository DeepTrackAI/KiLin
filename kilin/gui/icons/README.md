# KíLín GUI icons and attribution

This folder contains the images used by the desktop window, welcome screen,
and project sidebar. The current mosaic-style mascot exports include:

- `kilin-qilin.png` and `kilin-qilin-dark.png`: full-body mascot for the
  light and dark UI themes.
- `kilin-qilin-head.png` and `kilin-qilin-head-dark.png`: cropped head
  versions used by the application icon designs.
- `kilin-light.png` and `kilin-dark.png`: desktop window/Dock icons.
- `kilin-wordmark-light.svg` and `kilin-wordmark-dark.svg`: vector logotypes.
- `kilin-mosaic-accent.svg`: decorative mosaic accent.

The portable master artwork and the numbered mark/lockup exports are in
`assets/brand/` at the repository root. GUI resources are bundled with the
installed package; source artwork outside `kilin/` is not required at runtime.
